\# Installation



\## Prérequis



\* Java JDK 17 ou supérieur

\* Maven 3.9+

\* Git



\## Clonage



```bash

git clone https://github.com/medamineziani/projet-long.git

```



\## Compilation



```bash

cd projet-long/pl

mvn clean install

```



\## Exécution



```bash

mvn javafx:run

```
