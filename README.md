# IDE7 - Environnement pédagogique Java avec UML

## Présentation

IDE7 est un environnement de développement intégré (IDE) conçu pour faciliter l'apprentissage de la programmation orientée objet en Java.

Le projet combine plusieurs fonctionnalités pédagogiques :

* Éditeur de code Java
* Diagrammes UML
* Exécution et débogage
* Auto-complétion intelligente
* Gestion de projets Java

L'objectif est de créer un lien direct entre la conception UML et l'implémentation Java afin d'améliorer la compréhension des concepts orientés objet.

---
